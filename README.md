# Bemba-English Coding Platform

A bilingual programming environment allowing users to code using both English and Bemba keywords.

## Features
- Bemba → Python keyword translation
- Secure Docker-based execution
- User authentication (JWT)
- Code history storage
- Web-based IDE

## Tech Stack
Backend: Flask
Frontend: React
Database: PostgreSQL
Containerization: Docker

## Deployment
Frontend: Vercel
Backend: Render
Database: Supabase
